# BiteWind 🎣🌊

낚시인을 위한 물때·바다날씨 앱 (Flutter, Android/iOS).
아이폰 기본 날씨 앱의 UI/UX를 따릅니다 — 시간대별 그라데이션 배경, 반투명 카드, 지점 스와이프.

## 주요 기능

- **물때**: 음력 기반 물때 표시. 지점 해역에 따라 서해 **7물때식** / 남해동부·동해 **8물때식** 자동 전환
- **조석**: 오늘 조위 곡선(현재 시각 마커), 만조·간조 시각/조위 (오늘~내일)
- **날씨**: 시간별 기온·바람·파고, 현재 수온
- **일출·일몰·월령**: 천문 계산 (API 불필요)
- **낚시 지수**: 국립해양조사원 공식 **바다낚시지수** 예보 — 인근 낚시포인트의
  어종별(감성돔·농어·돌돔·우럭·참돔 등) 오전/오후 등급.
  키가 없거나 포인트가 멀면(>40km) 자체 휴리스틱 점수로 폴백
- **지점 검색**: 조위관측소 + 내장 장소(해수욕장·선착장·항구 등 약 90곳) +
  임의 지역(카카오 로컬 검색, 없으면 OpenStreetMap 폴백). 조석은 최근접 관측소에
  자동 매핑되며 **관측소 20km 이내**인 지역만 추가 가능. 스와이프 삭제, 드래그 정렬
- **주변 5km**: 상세 페이지 지도(OSM)에 화장실·편의점·낚시점 블릿 마커 +
  Windy 스타일 바람 애니메이션. 탭하면 네이버지도·카카오맵·티맵으로 연결
- **주간 물때**: 7일치 물때·만조/간조 표
- **알림**: 지점별 만조·간조 1시간 전 로컬 알림 토글
- **내 위치**: GPS로 최근접 관측소(20km 이내) 물때를 홈 상단에 표시
- **오프라인**: 마지막 데이터를 캐시해 신호가 없어도 표시 (기준 시각 표기)

## API 키 설정

키가 없으면 **샘플(목업) 데이터**로 동작합니다. 실제 데이터를 보려면:

1. **바다누리 (필수)** — 조석·수온·바람
   [바다누리 해양정보 서비스](http://www.khoa.go.kr/oceangrid/khoa/intro.do)에서
   회원가입 → 오픈API 인증키 발급 (무료, 일 20,000건)
2. **기상청 (선택)** — 단기예보. [공공데이터포털](https://www.data.go.kr)에서
   "기상청_단기예보 조회서비스" 활용신청.
   키가 없으면 자동으로 Open-Meteo(무료, 키 불필요)를 사용합니다.

발급받은 키를 `assets/config/api_keys.json`에 입력:

```json
{
  "khoaServiceKey": "여기에_바다누리_인증키",
  "kmaServiceKey": "여기에_기상청_인증키_(없으면_빈칸)",
  "dataGoKrServiceKey": "여기에_공공데이터포털_인증키_(바다낚시지수)"
}
```

공공데이터포털 키는 **Decoding(원본) 키**를 넣습니다 — URL 인코딩은 앱이 처리합니다.
바다낚시지수는 [해양수산부 국립해양조사원_바다낚시지수 조회](https://www.data.go.kr/data/15142486/openapi.do)
활용신청 후 사용 가능합니다.

> ⚠️ 키를 넣은 뒤 이 파일을 공개 저장소에 커밋하지 마세요 (.gitignore에 등록되어 있습니다).

## 빌드·실행

```bash
export PATH="$HOME/development/flutter/bin:$PATH"

flutter pub get
flutter test                 # 물때·천문 계산 테스트
flutter run                  # 연결된 기기에서 실행
flutter build apk            # Android 릴리스 APK
flutter build ios            # iOS (Xcode 필요)
```

## 디자인

[DESIGN.md](DESIGN.md)의 디자인 시스템(Intercom 스타일)을 따릅니다 — 크림 캔버스(#F5F1EC),
차콜 잉크(#111111), 흰색 카드 + 1px 헤어라인(그림자 없음), Fin 오렌지(#FF5600)는
낚시 지수에만 사용. 디자인 토큰은 [theme.dart](lib/ui/theme.dart)에 정의되어 있고,
서체는 Saans 대체로 [Pretendard](https://github.com/orioncactus/pretendard)(OFL)를 번들합니다.

## 데이터 출처

- 조석·수온·관측: 국립해양조사원 [바다누리 해양정보](http://www.khoa.go.kr/oceangrid/khoa/intro.do)
- 날씨: 기상청 단기예보 / [Open-Meteo](https://open-meteo.com) (폴백)
- 일출·일몰·월령: 앱 내 천문 계산 (NOAA 근사식)

## 구조

```
lib/
├── models/          # 데이터 모델 (관측소, 조석, 날씨)
├── logic/           # 물때(7/8물때식)·일출일몰·월령·낚시지수·기상청격자 계산
├── services/        # KHOA·기상청·Open-Meteo API, 목업, 저장소
├── data/            # 기본 관측소 목록 (런타임에 API로 갱신)
└── ui/              # 홈(PageView)·지점화면·지점관리·차트·카드 위젯
```
